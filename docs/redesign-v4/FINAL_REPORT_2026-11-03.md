### Исправлено 03.11

1. **Карта: маркеры по видимой области не грузились (404, в том числе на проде).** Модуль `/map/viewport/*` не был подключён в API. Подключён в `app.module.ts`. **Нужна выкладка API.**
2. **Админка, «Ссылки на фиды»: страница сдвигалась вбок на всех экранах.** Скрытые подписи кнопок вылезали за таблицу. Заменены на `aria-label`. Кнопки стали крупнее (36 px), у кнопки удаления появилась подпись.
3. **Админка, «Импорт фидов»: страница уходила в бесконечную перерисовку**, пока не загрузились источники.
4. **Админка на телефоне: шесть таблиц обрезались без прокрутки.** Это Застройщики, Корпуса, Справочники, Регионы, Источники данных и Telegram. Теперь они прокручиваются вбок.
5. **«Метро» в настройках админки.** Скрыт шаблон «у метро». Текст по умолчанию «фильтры по району и метро» заменён на «по району и сроку сдачи».
6. **Формы заявок на телефоне.** У галочки согласия зона нажатия теперь 40 px вместо 16 px.
7. **Вход.** Кнопка «показать пароль» стала 40 px, у неё появилась подпись.
8. **Фото эксперта.** Убрано предупреждение React о `fetchPriority`.

## Что осталось

### Как только сервер поднимется (делаю я)
1. Выложить фронтенд и API с правками 03.11. Для API — бэкап `dist`, сборка и перезапуск сервиса.
2. Прогнать `browser-qa.mjs` по живому сайту и снять Lighthouse.
3. Проверить карту `/map` на проде и координаты офиса в настройках. В базовой настройке платформы LiveGrid офис стоит в Белгороде.

### От заказчика
- Новый адрес фида «Хозяин Морей»: старый недоступен, лоты не обновляются.
- Площади и фото корпуса в выгрузке «Граф Толстой». Без площадей фид нельзя загрузить с нуля, он только обновляет уже заведённые квартиры.
- Фото двух ЖК без обложки, их можно загрузить в админке.
- Адреса, координаты, описания и застройщики всех ЖК.
- Рабочий ключ Яндекс.Карт.
- Подтверждённый телефон для шапки сайта.
- Настоящие новости вместо заглушек.

### Бэкенд, отдельная задача
- Публичный API отдаёт неопубликованные объявления (`/api/v1/listings/:id`).
- Корпуса заведены дважды («Корпус 1» и «1»).
- «Импорт фидов» в админке — старый механизм TrendAgent. Для ЮгАкцента он не нужен и падает с 500; можно убрать из меню.
- Мелкие иконки в админке на телефоне (панель редактора новостей, галочки в таблицах).
- На сервере заполнено 92 % диска. Это могло стать причиной остановки, нужно проверить.
