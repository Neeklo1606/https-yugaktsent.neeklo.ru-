# ЮгАкцент — как работать с админкой (для сотрудников агентства)

Адрес: `https://<домен>/admin` (сейчас `https://yugaktsent.neeklo.ru/admin`). Вход — email и пароль, которые выдаёт администратор
(«Пользователи»). Каждому сотруднику — своя учётная запись; общий служебный логин `admin@…` не используйте —
под ним работает автоматическое обновление фидов.

**Быстрый поиск:** ⌘K (Mac) или Ctrl+K — раздел, ЖК по названию, квартира по номеру, «Добавить фид».

## Каждый день
| Задача | Где | Как |
|---|---|---|
| Новые заявки | «Заявки» | Открыть заявку → статус «В работе» → после звонка «Связались» / «Показ назначен». Просроченные подсвечены на «Обзоре». |
| Что требует внимания | «Обзор» → «Требует внимания» | Список ЖК без фото, адреса, координат, описания, застройщика, срока сдачи — кликните и заполните. |
| Фиды обновляются? | «Фиды и источники» | Сводка сверху: «С ошибкой» должно быть 0. Красный статус — откройте «История обновлений» в строке. |

## ЖК и квартиры
- **Квартиры, цены и статусы приходят из фидов застройщиков** каждые 6 часов. Проданные снимаются с сайта сами.
  Руками квартиры из фидов не правьте — следующее обновление перезапишет цену и статус.
- **Карточку ЖК** («Жилые комплексы» → ЖК) можно дополнять: описание, адрес, координаты для карты, застройщик,
  срок сдачи, фото (обложка — фасад, не интерьер). Поля, исправленные вручную, фид не перезаписывает.
- **Новый ЖК:** «Фиды и источники» → «Добавить фид» → название, город, ссылка на выгрузку (Profitbase, ЦИАН, ДомКлик).
  ЖК появится на сайте через несколько минут; в строке будет ссылка «Открыть на сайте».
- **Остановить обновление** ЖК — переключатель «Обновлять» в строке фида (ЖК остаётся на сайте).
- **Объекты вне фидов** (вторичка, дома, участки, коммерция) — «Объекты» → «Добавить».

## Контент
- **Баннеры главной** — до 5 слайдов: фото, заголовок, кнопка со ссылкой.
- **Новости** — «Новости»: черновик → публикация.
- **Эксперты** — страницы сотрудников: фото, биография, видео, контакты, QR для визитки.

## Подключения («Ключи и подключения», только администратор)
- **Заявки в Telegram:** токен бота от @BotFather → «Проверить бота» → менеджеры пишут боту `/admin` → одобрить в «Telegram-уведомления».
- **CRM:** адрес вебхука amoCRM / Битрикс24 / Make → «Отправить тестовую заявку».
- **Яндекс Метрика:** номер счётчика. Метрика грузится только после согласия посетителя на cookie.
- **Вебмастер / Search Console:** коды подтверждения — сами попадут в код страниц.
- **Яндекс Карты:** ключ, ограниченный вашим доменом.

## Реквизиты и юридическое
«Настройки сайта» → «Юридическая информация»: юрлицо, ИНН, ОГРН, адрес — выводятся в подвале и в политике обработки
персональных данных (152-ФЗ). Тексты политики, согласия и соглашения — на страницах `/privacy`, `/personal-data-consent`, `/terms`.

## Если что-то не так
- Сайт не открывается или очень медленный — напишите разработчику; сервер сам перезапускает API при зависании (за ~15 с).
- Фид с ошибкой — сообщение в «Истории обновлений» подскажет причину (нет площади/цены, недоступна ссылка, сертификат).
- «Журнал действий» показывает, кто и что менял.
