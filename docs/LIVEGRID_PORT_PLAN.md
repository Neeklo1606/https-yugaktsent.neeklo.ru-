# Перенос админки и каталога LiveGrid на ЮгАкцент: разбор и план

Репозиторий: https://github.com/letoceiling-coder/livegrid.ru (последний коммит 07.03.2026). Разбор от 11.11.2026.

## Главный вывод

Наш сайт — это **более поздняя и доработанная версия того же кода LiveGrid**: те же файлы (`RedesignCatalog`, `ComplexCard`, `Chessboard`, `ApartmentTable`, `MapSearch`, `admin/…`), но у нас бэкенд на NestJS вместо Laravel, и большая часть заглушек уже заменена на рабочие функции.

Поэтому «перенести админку и каталог LiveGrid как есть» означало бы **откатить сайт назад**. Правильный путь — забрать из LiveGrid то немногое, что у них сделано лучше, и закрыть наши оставшиеся пробелы.

## Админка: LiveGrid против нас

В LiveGrid две админки:

- **`/admin` («Live Grid CMS») — макет.** Все страницы хранят данные в localStorage браузера:
  - редактор страниц и drag-and-drop конструктор;
  - медиатека (файлы пропадают после перезагрузки);
  - пользователи;
  - настройки (кнопка «Сохранить» ничего не делает).

  Изменения до сайта не доходят.
- **`/crm` — рабочая, но сырая.** Редактирование идёт через `prompt()` и сырой JSON, нет таблиц, пагинации и массовых действий. Нет заявок, новостей и корпусов.

| Раздел | LiveGrid | У нас |
|---|---|---|
| ЖК, корпуса, квартиры | CRM: ЖК и квартиры через JSON-окна, корпусов нет | Таблицы, редактор ЖК, мастер объявлений, корпуса, модерация (API) |
| Заявки | Только приём телефона, списка в админке нет | Список, статусы, ответственные, карточка заявки, Telegram |
| Фиды | Запуск artisan-команд кнопкой (TrendAgent JSON) | Синхронизация Profitbase, DomClick, ЦИАН, JCAT каждые 6 ч |
| Новости | Нет админки | Есть (API) |
| Медиа | В CRM настоящая, в /admin — фальшивая | Настоящая (API, проверка типа файла) |
| Пользователи и роли | Проверяется только admin | admin, editor, manager, agent, журнал действий |
| Справочники (районы, застройщики, отделки) | Есть отдельный экран | Есть «Застройщики» и «Справочники», не все в меню |
| Конструктор страниц | Drag-and-drop, но только в localStorage | Редактор секций главной и баннеров через API |

**Что стоит забрать из админки LiveGrid:**

1. **Справочники одним экраном.** Районы, застройщики, отделки, типы домов с позицией и вкл/выкл.
2. **Собственность полей «фид или менеджер».** Флаг «изменено вручную, фид не перезаписывает» на уровне поля. Сейчас ручная правка цены или описания ЖК может быть затёрта следующей синхронизацией.
3. **Генерация формы по схеме.** Как `GenericEditor` у них: для новых блоков главной не придётся писать форму руками.

**Что брать не нужно:** макет `/admin` на localStorage, EAV-модель «объекты/свойства» (у них не подключена к сайту), запуск команд из браузера.

## Каталог: LiveGrid против нас

| Возможность | LiveGrid | У нас |
|---|---|---|
| Фильтры в боковой панели, мобильная шторка | Есть | Есть |
| Фильтр по комнатам для ЖК | Не работает (бэкенд игнорирует) | Работает |
| Плитка, список, карта | Есть; в каталоге квартир карта пустая | Есть |
| Карточка ЖК: карусель фото, цены «от» по комнатам | Есть (строки по комнатам при наведении) | **В каталоге одно фото, без цен по комнатам.** Карусель и цены по комнатам — только в «Популярных» на главной |
| Подсказки поиска при вводе (ЖК + квартиры) | Есть | **Нет**, только поиск по Enter |
| Выбор «показывать по 20/30/50/100» | Есть | Нет (не критично) |
| Шахматка | Квартиры одного этажа перезаписывают друг друга, статусы фиктивные | По корпусам, с настоящими статусами |
| Таблица квартир на странице ЖК с фильтром по комнатам | Есть | Есть |
| Похожие ЖК и квартиры | API есть, на страницах не выводятся | Есть |
| Избранное | Заглушка | Работает |
| Кнопки «Позвонить», «Записаться», «Ипотека» | Без обработчиков | Формы заявок работают |
| Планировки | Мок-данные | Реальные планы из фидов |

**Что стоит забрать в каталог:**

1. **Карточка ЖК как в LiveGrid** (и как в нашем блоке «Популярные ЖК»):
   - карусель фото;
   - «Квартир N»;
   - цены «от» по комнатности с отточием;
   - срок сдачи.

   Сделать единой для каталога, главной и карты.
2. **Подсказки поиска при вводе:** до 5 ЖК и 5 квартир, плюс разбор фраз вида «2к до 8 млн» (их `SearchQueryParser`).
3. **Счётчики в фильтрах:** «Застройщик X (124)». У LiveGrid их нет, но это добьёт до уровня ЦИАН.
4. **Выбор количества на странице** — по желанию.

## Пробелы на нашей стороне, найденные при сравнении

1. **«Фиды и источники» в админке хранят список в localStorage браузера.** Это нарушает ТЗ. Настоящая страница «Ссылки фидов» (`/admin/feed-links`, API) есть, но её нет в меню, а реальные фиды до сих пор лежат в настройках сервера (`FEEDS_JSON`). Нужно:
   - перенести 8 фидов в базу через страницу «Ссылки фидов»;
   - сохранить ключи состояния синхронизации, чтобы не появились дубли;
   - показать статус последней синхронизации и ошибки;
   - убрать localStorage-версию.
2. **Ручные правки против фида** (см. п. 2 по админке).
3. **Заявки → Telegram** не проверены вживую: нужен токен бота.

## План работ

| Этап | Что | Объём | Нужно от вас |
|---|---|---|---|
| 1 | Фиды в админке по-настоящему (п. 1 пробелов) | 0,5–1 день | — |
| 2 | Единая карточка ЖК как в LiveGrid в каталоге и на карте | 0,5 дня | — |
| 3 | Подсказки поиска при вводе + разбор «2к до 8 млн» | 0,5–1 день | — |
| 4 | Защита ручных правок от перезаписи фидом | 0,5 дня | — |
| 5 | Справочники одним экраном, счётчики в фильтрах | 1 день | — |
| 6 | Telegram-заявки, бэкап вне сервера, Метрика | 0,5 дня | Токен бота, место для бэкапа, номер Метрики |

Этапы 1–5 не требуют ничего от заказчика и делаются подряд. Каждый выкладывается отдельно с бэкапом и проверкой на проде.
