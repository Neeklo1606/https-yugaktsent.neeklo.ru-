# ЮгАкцент — правки по звонку с заказчиком (24.11.2026)

Референс заказчика: ap-r.ru («Ассоциация застройщиков»). Задача — взять ~20 % их функций, без перегруза.
Статус: **выложено на прод 24.11** (коммиты 574b100 + 136e795, ветка release/2026-11-12).

## Что сделано

### Подвал (жалоба «растянуто, ничего не понятно»)
- Причина: `tailwind-merge` в `cn()` выкидывал класс тёмного фона из-за класса градиента → белый текст на белом фоне.
- Исправлено: фон задан в самом `.bg-footer-gradient` (+ тёмная тема). Убрана карта-iframe 320 px.
- Высота на десктопе **~980 → 354 px**, пять аккуратных колонок; на телефоне — две колонки ссылок.

### Меню и разделы
- Убран дубль «Каталог недвижимости» — остался «Новостройки» (ведёт в каталог, подсвечивается на любой странице каталога).
- Добавлен пункт **«Ипотека»** → новая страница `/mortgage` (калькулятор, программы, заявка). SEO-мета, prerender и sitemap.
- Коммерция не добавлялась — по решению на звонке (позже, если появится фид).

### Типы недвижимости
- У ЖК новое поле «Тип жилья»: квартиры / апартаменты / коттеджи (миграция `20261124120000_block_housing_content`;
  ЖК с «Hotel» в названии сразу помечаются апартаментами — Eden Family Hotel, Николай 1 Hotel&Spa).
- В каталоге вкладки **«Все | Квартиры | Апартаменты | Коттеджи»** (параметр `?housing=`). Коттеджей пока нет —
  показывается «Коттеджные посёлки скоро появятся» с кнопкой заявки.
- В админке ЖК — выбор типа жилья.

### Шахматка (главный акцент)
- **Один блок «Квартиры и цены»** с вкладками **«Шахматка | Списком | Планировки»** вместо трёх блоков,
  дублировавших одно и то же.
- Шахматка одинакова для всех секций (раньше часть секций показывалась списком, часть сеткой — режим
  переключался сам). Этажи сверху вниз **без пропусков**, окна по стоякам, в ячейке — комнатность, площадь
  (или №), цена «9,54 млн».
- **Проданные видны**: серые окна «продана / нет в продаже», над сеткой «73 свободно из 121 · 11 этажей».
  API теперь отдаёт в шахматку и проданные лоты (статус SOLD из фида и снятые с продажи с номером), без цены
  и без ссылки, с защитой от дублей (тесты `blocks-chessboard.util.test.ts`).
- Справа (на телефоне сверху) панель как у референса: **Дом (литер) → Секция → Комнаты**, легенда со счётчиками.
  40 секций «На высоком берегу» теперь не 40 вкладок в строку, а литер + номер секции.
- По умолчанию открывается дом с наибольшим числом квартир (первая секция бывала с одной квартирой).
- Клик по свободной квартире — её страница; наведение — превью планировки; на телефоне — шторка.
- Вкладка «Списком»: фильтр «Все дома», не зависит от выбранного в шахматке дома.

### Карточка ЖК
Порядок блоков: Квартиры и цены → Генплан → О комплексе (с «Читать полностью») → Видеообзор → Ипотека →
Частые вопросы → Заявка → Похожие ЖК (по городу).
- **Генплан**: картинка (открывается крупно) или 3D-ссылка застройщика (грузится по нажатию). Блок появляется,
  когда генплан заполнен в админке.
- **Видеообзор**: ссылки VK Видео / YouTube / Rutube → встроенный плеер по нажатию.
- **Ипотечный калькулятор** в каждой карточке (цена ЖК подставляется), кнопка «Подобрать ипотеку» → заявка.
- **Частые вопросы**: свои вопросы из админки + автоматически по данным ЖК (цена, срок сдачи, застройщик,
  адрес, отделка, количество домов — вопрос появляется, только если есть ответ в данных) + общие (ипотека,
  первый взнос, эскроу). Разметка FAQPage для поисковиков.
- Закреплённая панель с ценой и «Записаться на просмотр» при прокрутке (десктоп — под шапкой, телефон — снизу).
- **Админка ЖК** (`/admin/blocks/:id`): тип жилья, доп. фото (загрузка нескольких), генплан (загрузка или ссылка),
  3D-генплан, видео (по ссылке в строке), свои частые вопросы.

### Ипотека
- Калькулятор: стоимость, взнос (% и ₽), срок, ставка; программы-кнопки (по умолчанию Семейная 6 %, IT 6 %,
  Базовая 20 % «рыночная, уточняйте»). Платёж, сумма кредита, переплата, оговорка «не оферта».
- Ставки редактируются в настройках сайта: `mortgage_programs_json`, список банков — `mortgage_banks_json`
  (`[{"name":"Сбер","rate":5.9}]`; нажали банк — ставка подставилась). Пока банков нет — блок банков не показывается,
  ставки банков не выдумываются.

### Карта и подбор
- Каталог на десктопе ≥1280 px: **список слева + карта справа** (переключатель «Список | Список + карта»,
  запоминается). Клик по метке — подсветка карточки; наведение на карточку — подсветка метки.
  На телефоне — плавающая кнопка «Показать на карте / списком».
- Главная: кнопка **«Выбрать ЖК на карте»** в поиске (на десктопе и телефоне).
- **Квиз «Не определились с городом?»** на главной: 4 вопроса (сколько вас, бюджет, что важнее, когда покупка) →
  рекомендация города со ссылкой на его новостройки + имя/телефон (ответы уходят в комментарий заявки).

## Что нужно от заказчика / решения
- **Координаты ЖК**: ни у одного ЖК нет широты/долготы → карты (каталог, /map, карточка) пока пустые.
  Заполнить в админке (ЖК → Широта/Долгота) или дать адреса — проставим.
- Фото, генпланы, видео, описания (своими словами) — грузить в админке ЖК; для показа Трендагенту заполнить 2–3 ЖК.
- Ставки банков для калькулятора (или оставить только программы).
- Фиды: «Граф Толстой» — на сайте 0 квартир (в выгрузке нет площади и цены); нужна ссылка на **второй фид**,
  проверим его. «Хозяин Морей» — у застройщика неправильный сертификат на сервере выгрузки, нужно, чтобы
  они его исправили (обходить проверку сертификата небезопасно).
- Доступы: Reg.ru (DNS), Яндекс Бизнес (ключ карт), CRM (заявки как «покупатель»).
