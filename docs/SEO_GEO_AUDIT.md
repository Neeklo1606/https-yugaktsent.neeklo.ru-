## Было → стало

| Проблема | Было | Стало |
|---|---|---|
| Статические страницы в HTML | `/about`, `/privacy`, `/news`, `/contacts`… отдавали HTML главной: title главной и `canonical=/` с `index, follow` — для поисковика это дубли главной | Пререндер 8 страниц со своими title/description/canonical (`apps/web/scripts/prerender-seo.mjs`) |
| Несуществующие адреса | HTTP 200 + HTML главной | **HTTP 404**, `noindex`, «Страница не найдена» (nginx: `404.html`) |
| Динамические маршруты (`/apartment/:id`, `/news/:slug`, `/admin`) | HTML главной с canonical на главную | `spa.html` без canonical и без noindex — мету ставит приложение |
| H1 главной | Заголовок слайда («ГК Sun Garden»), менялся каждые несколько секунд | Постоянный H1 «Новостройки Анапы и Майкопа — агентство недвижимости ЮгАкцент» (визуально без изменений) |
| Canonical каталога | Включал все фильтры (цена, комнаты, поиск) — тысячи вариантов | Только `region_id`, `type`, `market`, `group`; utm вырезаются везде |
| robots.txt | `Disallow: /admin` | + `/login`, `/favorites`, `/presentation/`; API для рендеринга открыт |
| sitemap.xml | Без согласия ПД и новостей | + `/personal-data-consent`, новости (сейчас 0 опубликованных) |

## Региональное SEO

Анапа и Майкоп разделены параметром `?region_id=` (9 и 10). Приложение ставит title «Анапа · Каталог…» и
canonical с `region_id`, но в исходном HTML у `/catalog?region_id=10` canonical — `/catalog` (nginx не различает
query). **P2:** сделать адреса `/anapa`, `/maykop` (или `/catalog/maykop`) с пререндером и своим H1. Фиктивные офисы
в Майкопе не создавались; адрес агентства — только Анапа, ул. Терская, 88.

## GEO (поиск ИИ)

| Критерий | Состояние |
|---|---|
| Контент в HTML без JS | **Нет** — в HTML только мета; тексты, цены, списки рендерит JS. Яндекс и Google рендерят, многие ИИ-краулеры — нет. P1: пререндер содержимого карточек ЖК (название, город, застройщик, цены «от», срок сдачи, дата обновления) |
| Однозначность названий/городов | Название ЖК, город и адрес из фидов; застройщики в базе не заведены (0) |
| Дата обновления цен | Синхронизация каждые 6 ч; дата на карточке не выводится — P2 |
| Структурированные данные | `SeoJsonLd` (Organization/хлебные крошки) — соответствуют содержимому; отзывов/рейтингов нет и не добавлялись |
| FAQ | Не добавляли — нет подтверждённых ответов от агентства |
| llms.txt | Не создавали (не стандарт, отдаёт 404) |

Позиции в поиске и цитирование ИИ не обещаются.
