## 1. Что это за проект (для нового разработчика)

**Происхождение.** Код вырос из платформы-агрегатора недвижимости LiveGrid, рассчитанной на много агентств, с CRM, биллингом и т.д. Под ЮгАкцент (одно агентство, Анапа) её перекрасили и упростили на уровне интерфейса. Внутри осталось много модулей LiveGrid, которые этому сайту не нужны. Это главный источник «лишнего» в коде (раздел 4.4).

**Стек**
- Монорепо pnpm, Node ≥ 22.
- `apps/web`: Vite, React 18, TypeScript, Tailwind, React Query. Тут и публичный сайт (`src/redesign/*`), и админка (`src/admin/*`).
- `apps/api`: NestJS, Prisma, PostgreSQL 16 + **PostGIS**, Redis. Около 46 тыс. строк, 40 модулей.
- `packages/database`: схема Prisma и 53 миграции; в 17 из них raw SQL с PostGIS.
- `deploy/yugaktsent/profitbase-sync`: отдельная служба. Раз в 6 часов и по кнопке из админки забирает XML-фиды Profitbase и пишет их через админский REST API.
- **nginx** на сервере: SPA, прокси `/api`, ресайзер фото `/img/<w>/…` (Profitbase и свои загрузки), security-заголовки, rate-limit. На том же nginx живут ещё 7 сайтов.
- Процессы: systemd-юниты `yugaktsent-api` и `yugaktsent-profitbase-sync`.

**Где что лежит**

| Что | Где |
|---|---|
| Публичные страницы (новый дизайн) | `apps/web/src/redesign/pages/*` |
| Админка | `apps/web/src/admin/*`, маршруты в `apps/web/src/App.tsx` |
| API | `apps/api/src/modules/*`, подключение модулей в `apps/api/src/app.module.ts` |
| Схема БД | `packages/database/prisma/schema.prisma` |
| Деплой | `deploy/yugaktsent/*` (`deploy-full.sh`, systemd, `env.example`) |
| Актуальный конфиг nginx (применён на проде) | `docs/ops/nginx-yugaktsent.proposed.conf` |
| QA-скрипт (адаптив, ошибки, 375/768/1280) | `deploy/yugaktsent/qa/browser-qa.mjs` |
| Отчёты | `docs/AUDIT_2026-10-30.md`, `docs/redesign-v4/*` |

**Важные особенности**
- **Фронт собирается только с флагами**, иначе пропадут ресайз фото и правильный домен:
  ```bash
  VITE_PUBLIC_SITE_URL=https://yugaktsent.neeklo.ru VITE_DEFAULT_BRAND=ЮгАкцент VITE_DEFAULT_REGION_CODE=anapa VITE_IMAGE_PROXY=1 VITE_IMAGE_PROXY_LOCAL=1 VITE_ADMIN_DEMO_EDITING=1 pnpm build:web
  ```
  Деплой: `dist` → `apps/web/dist.new`, затем переименование, старая сборка остаётся как `dist.prev-<время>`.
- После ручных правок БД нужно сбросить кэш каталога и пересобрать sitemap (`refreshCatalogCache` и `regenerateSitemap` через админский API).
- Локально без PostGIS не работают карта (`/map/viewport/*` → 500) и одна миграция.
- `apps/web/staging-guard.ts` в dev-режиме блокирует запись в прод-API. В боевую сборку он не попадает (проверено).
- **URL фидов Profitbase содержат секретный токен.** Их нельзя выводить в логи, тикеты и клиентский код.
