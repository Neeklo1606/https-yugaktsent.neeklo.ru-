## 4. Предлагаемый конфиг nginx — нужен ваш OK

Файл: `docs/ops/nginx-yugaktsent.proposed.conf`. Инструкция по применению и откату — в шапке файла.

- **Ресайзер фото.** Внутренний сервер на `127.0.0.1:8099` уменьшает фото Profitbase модулем `image_filter`. Обрабатываются только хосты `pbNNNN.profitbase.ru`, так что открытым прокси он не станет. Результат кэшируется на 30 дней, кэш ограничен 700 МБ: на диске всего 2,5 ГБ свободно.
- **Безопасность.** Закрыт Swagger, добавлены заголовки и лимиты, закрыта регистрация.
- **Что нужно на сервере:** `apt install libnginx-mod-http-image-filter`, затем `nginx -t` и `reload`. На том же nginx живут ещё 7 сайтов, поэтому делать с бэкапом `/etc/nginx`.
- **После применения:** пересобрать фронт с `VITE_IMAGE_PROXY=1` и выкатить.

## 5. Админка: что работает

**Работает с реальным API (сохраняется в БД):**
- ЖК: название, slug, описание, статус, продвижение, старт продаж;
- объекты: ручные формы по типам, мастер, модерация, акции;
- застройщики, корпуса, регионы, справочники;
- медиа: загрузка фото работает (`POST /admin/media/upload`);
- заявки, задачи, пользователи, журнал действий, Telegram-уведомления, нейросети;
- новости, включая SEO-поля, которые теперь доходят до сайта;
- настройки сайта, главная, баннеры: тексты главной, SEO главной (`site_title`, `meta_description`, `og_image`), SEO-интро лендингов, FAQ.

**Фиды:**
- Загрузить файл фида (XML/CSV/Excel) через админку **нельзя**: такого endpoint нет.
- Backend умеет только JSON-фиды TrendAgent: страницы `/admin/feed-import` (запуск, остановка, история) и `/admin/feed-links`. Из меню они убраны, потому что TrendAgent заказчик не использует.
- Profitbase синхронизируется отдельной службой `yugaktsent-profitbase-sync` автоматически, без админки.
- Пункт меню «Фиды и источники» — демо-интерфейс без API.
- Нужно сделать (B5, C6): загрузку XML-фидов Яндекс/Авито/Циан, журнал синхронизаций Profitbase в админке, кнопку «синхронизировать сейчас».

**Демо, сохраняется только в браузере:**
- «Эксперты», «Тема сайта», «Страницы» и редактор страниц.

**SEO, которое из админки не редактируется** (заголовки зашиты в коде):
- каталог, карта;
- «О компании», «Контакты» (title);
- юридические страницы.

Страницы ЖК и объектов берут SEO из данных сущности, поэтому оно меняется вместе с названием и описанием ЖК. Чтобы редактировать SEO любой страницы, нужна таблица SEO-страниц в API (backend, 1–2 дня).

**Карточка ЖК в админке неполная:**
- нет адреса, координат, застройщика, галереи и хода строительства (B3). При этом API уже принимает координаты и обложку.
- У всех 5 ЖК на проде адрес, координаты и описание пустые.
