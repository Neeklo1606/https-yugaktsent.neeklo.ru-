## Выполнено

**Сайт**
- 16 ЖК и 10 855 квартир из 18 фидов застройщиков, 4 города; обновление каждые 6 ч, проданные снимаются сами.
- Страницы ЖК и квартиры: первый экран «фото/планировка + карточка с ценой и действием», шахматка, «Показать ещё», похожие квартиры, карта.
- Телефон как приложение: отклик на касание, плавные переходы, «назад» на то же место, загрузка по касанию, установка на экран, градиенты.
- Загрузка: каркас страницы вместо «Загрузка…»; при сбое сети — «Не удалось загрузить» и «Повторить» (раньше писало «не найдено»).
- Скорость: Lighthouse телефон — главная 41 → 69–73, остальные 72–77; доступность и SEO 100; планировки ССК через наш кэш (2 → 0,25 с).
- SEO: своя страница с заголовком и разметкой у каждой квартиры (10 858), sitemap, robots, canonical; `llms.txt` для нейропоиска (Алиса, ChatGPT и т. п.).
- Юридическое: политика ПД, согласие, соглашение, баннер cookie, оговорки 38-ФЗ.

**Админка**
- «Фиды»: сводка, фильтры, ЖК / квартиры / фото по каждому фиду, история обновлений, «Обновлять» одним переключателем.
- «Ключи и подключения»: Telegram, CRM-вебхук, Метрика, Вебмастер, Карты.
- Всё по-русски, заготовки убраны, быстрый поиск ⌘K; исправлен вылет из админки каждые 15 минут.

**Надёжность и безопасность**
- Сторож API (перезапуск за ~15 с), ежедневная копия базы (проверена), откат каждой выкладки.
- CSP в режиме отчёта + приёмник отчётов; HTTPS/HSTS, заголовки безопасности, лимиты на вход и формы, ловушка для ботов.

- Доступность (23.11): заголовок H1 на «не найдено» и на главной для десктопа, подписи полей формы заявки и фильтров, мелкий текст 11 → 12 px.

**Проверки (23.11)**: тесты — сайт 213, API 54, синхронизация 34 (одной командой `deploy/yugaktsent/scripts/predeploy-check.sh`); браузерная проверка 306 страниц на 9 ширинах (320–1920 px) — 0 ошибок вёрстки.

**Документы к сдаче**: `docs/DOMAIN_MOVE_RUNBOOK.md` (переезд на домен), `docs/ADMIN_GUIDE_CLIENT.md` (инструкция сотрудникам).

## Осталось

**От заказчика** (без этого не сдать)
1. Реквизиты: юрлицо, ИНН, ОГРН, юр. адрес — 152-ФЗ.
2. Домен (Reg.ru): доступ к DNS и дата переезда.
3. Свой счётчик Метрики, коды Вебмастера и Search Console, ключ Яндекс Карт под домен.
4. Куда слать заявки: Telegram-бот и/или вебхук CRM, почта (SMTP).
5. Фиды: «Граф Толстой» (нет площади и цены у 361 квартиры), «Хозяин Морей» (сертификат), ссылка на ЖК «Центральный».
6. Контент ЖК: застройщики, описания, адреса, координаты, фото фасадов.
7. Юрист проверяет тексты политики и соглашения.

**От нас (решения и доступы)**
1. Хранилище для копий базы вне сервера (S3 / Яндекс Облако / Яндекс Диск).
2. Сменить пароль служебного администратора, завести личные учётки.
3. Убрать Метрику, которую вставляет панель хостинга.
4. Диск сервера занят на 86 % — место занимают другие проекты (ComfyUI 214 ГБ, Docker 83 ГБ, LLM 55 ГБ, Lovable 46 ГБ); сам ЮгАкцент ~4 ГБ.
5. Решения: 2FA для админов, GlitchTip, внешний мониторинг, конвертер WebP, переключатель «скрыть ЖК», офлайн-режим.
6. ~~nginx: `charset utf-8` для текстовых файлов~~ — сделано 23.11.
7. Через неделю без лишних отчётов — перевести CSP в блокирующий режим.
8. Проверить, что админка не выкидывает дольше 15 минут (нужен ваш вход).
