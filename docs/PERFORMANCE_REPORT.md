## Что сделано

1. **Preload картинки первого экрана в HTML** (`scripts/prerender-seo.mjs`): главная (первый слайд героя),
   каталог (обложка первой карточки), страницы ЖК (обложка галереи). Раньше картинка начинала грузиться
   только после цепочки «JS → настройки → регионы → список ЖК» (задержка до 4,9 с в трассе); теперь — сразу,
   с тем же `srcset`, без повторного запроса (проверено: инициатор `link`, один запрос).
2. **Основной бандл 392 → 298 КБ** (gzip 130 → 99 КБ): убраны неиспользуемый radix-тостер и корневой
   `TooltipProvider` (оба места с подсказками имеют свой Provider), `sonner` подгружается после первой отрисовки.
3. **CLS главной 0,083 → 0,001:** место под «Популярные ЖК» и «Квартиры в продаже» резервируется заглушками
   той же высоты (на телефоне лента — один ряд, а не два); секция больше не пропадает, пока город не определён.
4. **CLS каталога:** место под переключатель города резервируется до загрузки списка городов (иначе каталог
   прыгал вниз на 46 px).
5. Убраны `preconnect` к хостам Profitbase: фото идут через наш ресайзер, один из хостов мёртв.

## Что осталось до 90+

- **LCP 3,1–3,5 с** упирается в то, что страница — SPA: HTML пустой, картинка уже грузится заранее, но
  отрисовать её можно только после загрузки и выполнения JS. Следующий шаг — пререндер разметки первого экрана
  (SSR/статический HTML для главной, каталога и ЖК), 2–3 дня.
- Каталог: остаточный сдвиг 0,05 у первой карточки при смене заглушки на данные.
- Разброс Lighthouse ±10 баллов между прогонами — сравнивать только медианы.
