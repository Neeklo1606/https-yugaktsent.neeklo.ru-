## Что сделано

**Этап 1 (cb1ee78)**
1. Preload картинки первого экрана в HTML: главная, каталог, страницы ЖК, с тем же `srcset`, что у `<img>`.
2. Основной бандл 392 → 298 КБ (gzip 130 → 99 КБ): убраны неиспользуемый radix-тостер и корневой `TooltipProvider`, `sonner` после первой отрисовки.
3. Заглушки «Популярных ЖК» и «Квартир в продаже» точной высоты; место под переключатель города в каталоге.
4. Убраны preconnect к Profitbase.

**Этап 2 — разметка первого экрана в HTML (5093509, 72bab08, 2971d6e, 064b8ba)**
1. `src/ssr/prerender-entry.tsx` + `vite.ssr.config.ts`: главная, каталог и ЖК рендерятся в Node **теми же
   компонентами** с данными, загруженными их же запросами (несколько проходов: рендер → недостающие запросы → рендер).
2. Разметка кладётся в `#ssr-shell` перед `#root`; приложение убирает её в том же кадре, когда отрисовало страницу
   (`RemoveSsrShell`, `useLayoutEffect`) — без мигания и без hydration-ошибок.
3. Данные запросов (до 20 КБ на запрос) встраиваются как `window.__YUG_RQ__` и сразу попадают в кэш React Query:
   нет цепочки «настройки → регионы → ЖК», первый рендер совпадает с разметкой. Крупные списки квартир клиент грузит сам.
4. В оболочке грузится только картинка первого экрана и логотипы (иначе 20+ фото и планировок делили канал);
   из оболочки ЖК вырезаны шахматка, планировки, похожие ЖК (855 → 539 элементов).
5. Шрифт: только latin и cyrillic (latin-ext 83 КБ качался ради «₽»), плюс запасной шрифт с метриками Inter —
   подмена шрифта больше не сдвигает текст.
6. Свежесть: `deploy/yugaktsent/scripts/prerender-web.sh` перегенерирует HTML на сервере после каждой синхронизации
   фидов (вызов из `profitbase-sync`), запись файлов атомарная; ручной запуск — `bash deploy/yugaktsent/scripts/prerender-web.sh`.

Побочный эффект для SEO/GEO: в исходном HTML главной, каталога и ЖК теперь есть H1, названия ЖК, адреса, цены
«от», сроки сдачи — их видят краулеры без JS.

## Деплой фронтенда теперь

`vite build` → `vite build --config vite.ssr.config.ts` → `node scripts/prerender-seo.mjs` → rsync `dist/` и `dist-ssr/`
(оба нужны серверу для перегенерации после синхронизации).

## Что осталось

- Каталог: TBT от рендера сетки и фильтров на слабом CPU; дальнейший шаг — виртуализация списка/упрощение фильтров.
- LCP 3,0–3,4 с в симуляции ограничен скачиванием самой картинки (70–90 КБ на медленном 4G); следующий резерв — AVIF/WebP в ресайзере nginx.
