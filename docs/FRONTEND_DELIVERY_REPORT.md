**Как мерили**
- Lighthouse 12, профиль mobile (Moto G Power, simulated throttling: 4G, CPU ×4), системный Chrome headless, по одному прогону на страницу.
- **До** — боевой сайт `yugaktsent.neeklo.ru`: nginx, gzip, API на том же сервере.
- **После** — production-сборка этой ветки через `vite preview` на этом компьютере. API проксируется на боевой сервер через интернет (лишний сетевой круг на каждый запрос), ответы **без gzip**.

**Что сделано в фазе 6**
- **Переходы без спиннера.** `BrowserRouter future={{ v7_startTransition: true }}`: при навигации остаётся текущий экран, пока грузится следующий. Глобальный fallback — тонкая полоса сверху только при первой загрузке.
- **Предзагрузка кода страницы** по наведению, касанию и фокусу (`shared/lib/route-prefetch.ts`) — на карточках ЖК, объектов и эксперта. Учитывает режим экономии трафика.
- **Кэш публичных справочников между визитами** (`shared/lib/persisted-query.ts`): регионы, настройки сайта, список ЖК главной. Данные из кэша показываются сразу и в фоне сверяются с сетью.
- **Первый экран:** фото грузится только у текущего слайда, следующий — через 2,5 с. Пока данных нет — плейсхолдер той же высоты, поэтому CLS главной 0,388 → 0,001.
- **Яндекс.Карты** (~500 КБ) больше не грузятся на страницах без координат. Исправлен `useInViewOnce`: элемент, появившийся после первого рендера, раньше не отслеживался.
- **Логотипы** 126 и 106 КБ → по 12 КБ. Тот же знак, размер 582×144 (3× от высоты в шапке); оригиналы в `apps/web/brand-src/`.
- **Обложки новостей** (свои статичные): 202 / 109 / 66 / 49 КБ → 87 / 72 / 47 / 36 КБ, имена файлов прежние.
- **Доступность:**
  - контраст второстепенного текста `#64716E` → `#5B6865` (≥ 5:1 и на подложке);
  - `<main>` на главной, в каталоге, на ЖК и объекте;
  - скрытый H2 над выдачей каталога.

**Почему LCP всё ещё 5–8 с — и что это требует от backend**
- **Оригиналы фото Profitbase.** Обложка ГК Sun Garden — **4,3 МБ** (`pb19399.profitbase.ru`). Это LCP-кадр главной и каталога, и одно это фото весит больше всего остального на странице. Фронтенд не может уменьшить чужой файл.
  - Нужен серверный прокси: скачать → WebP/AVIF → размеры 480 / 960 / 1600 → своё хранилище (S3).
  - Тогда первый экран — ~80–150 КБ, и цель LCP ≤ 2,5 с становится реальной.
  - Прогонять фото через сторонний ресайз-сервис без согласования мы не стали.
- **Хост `pb16100.tochno.profitbase.ru` отдаёт поддельный TLS-сертификат.** Фото «Хозяин Морей» не грузятся ни у кого — нужна серверная загрузка.
- **Цепочка API первого визита** «настройки + регионы → ЖК»: на проде API отвечает быстрее, чем через локальный прокси, но два последовательных круга остаются.
  - Решение — отдавать регион и подборку ЖК в пререндере главной или одним эндпоинтом.

## 6. Как выкатывать (после согласования)

Ветка готова к ревью. Для выката:
1. Влить `redesign/v3` в `main` через PR.
2. На сервере выполнить `deploy/yugaktsent/deploy-full.sh`.

Вместе с выкатом:
- **Staging-guard на прод не влияет.** Он работает только в dev и preview, в production-сборке метки «Демо» нет.
- **Проверить на проде после выката:**
  - публичные маршруты;
  - вход в админку;
  - отправку заявки — настоящую;
  - Lighthouse с nginx/gzip.
- **Записать новые настройки** в админке (поддерживаются кодом): `about_youtube_url`, `telegram_url`, `youtube_url`, `vk_url`, `max_url`, а при желании — `theme_tokens`.
