## 5. Деплой 11.11.2026 (выполнен)

Сервер 31.192.111.33 общий (на нём ещё ~15 сайтов), поэтому `deploy-full.sh` не запускался: он пересобирает фронтенд на месте с простоем и перезаписывает nginx. Деплой точечный:

1. Бэкап БД `/root/db-backups/yug-20261110-2005.dump` (80 таблиц), копия на Mac владельца: `UGACENT/backups/`. **Восстановление проверено** в отдельную локальную БД `yug_restore_test`: 624 объявления, 2 ЖК, 51 настройка. 4 ошибки — только GIST-индексы PostGIS, которого нет локально.
2. Откат: `/root/rollback-api-dist-20261110-2005`, `/root/rollback-web-dist-20261110-2005`; код — `git checkout 4b2888d`.
3. Сервер: `git checkout release/2026-11-12` (от пользователя `admin`, deploy-ключ), `pnpm --filter @lg/shared build`, `pnpm --filter @lg/api build`, `systemctl restart yugaktsent-api`. Миграций нет.
4. Фронтенд собран локально с пререндером по боевому API, залит в `dist.new`, атомарная замена `dist`.
5. `configure-brand.sh` (на новом сервере не запускался): название, title, описание, email, координаты офиса Анапы вместо Белгорода; **отключены регионы импорта `msk` и `belgorod`** (еженедельный импорт TrendAgent мог залить на сайт московские объекты). Баг скрипта (NOT NULL `updated_at`) исправлен. Оставшиеся строки LiveGrid в настройках (`seo_landing_district_intro`, `contacts_email`) заменены; дефолты в `seed.ts` и `content-defaults.ts` переименованы под ЮгАкцент.
6. Ежедневный дамп БД: `yugaktsent-db-backup.timer` (03:40, хранение 14 дней), юниты в `deploy/yugaktsent/systemd/`. Первый прогон успешен.
