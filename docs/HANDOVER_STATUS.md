# ЮгАкцент — сверка прода с финальной версией и остаток работ

Дата сверки: 29.10.2026. Сервер: `93.188.187.124`, сайт `https://yugaktsent.neeklo.ru`.

## 1. Что на проде

- **Код.** Фронт собран из `main`, редизайн v3. Пересборка `main` дала тот же код, что лежит на сервере: отличаются только хэши в именах файлов и цены в пререндеренных страницах (они берутся из API при сборке).
- **Исходники на сервере** `/var/www/yugaktsent-lg` совпадают с репозиторием. Отличаются только sitemap-файлы, которые сервер генерирует сам.
- **nginx** отдаёт пререндеренные страницы: `try_files $uri $uri/index.html /index.html`.
- **Работают:** API (`yugaktsent-api`) и синхронизация Profitbase (`yugaktsent-profitbase-sync`).
- **Админка в демо-режиме.** В боевой сборке включён `VITE_ADMIN_DEMO_EDITING=1`. Можно показать экраны «Эксперты» и «Тема сайта». Правки сохраняются только в браузере того, кто редактирует, в API ничего не уходит. На каждом таком экране есть плашка «Демо · ожидает подключения backend».

### Осталось: backend и сервер

**Безопасность (P0, до публичного запуска):**
- **A1 — бэкапы.** Ежедневный `pg_dump` с копией вне сервера.
- **A2 — rate limiting.** Ограничить частоту запросов на логин, заявки и webhook.
- **A3 — Swagger и заголовки.** `/docs` (Swagger UI) сейчас открыт снаружи. Заголовков HSTS и CSP нет.
- **A4 — лимит выдачи.** `GET /listings?per_page=1000` отдаёт 1000 объектов, лимита нет.
- **A5 — регистрация и Telegram-webhook.** Endpoint `/auth/register` существует: на пустой запрос отвечает 400, а не 404. Закрыть его, проверить `secret_token` у Telegram-webhook.
- **A7 — учётки и секреты.** Удалить учётку `admin@livegrid.ru`, сменить пароли, сгенерировать секреты.
- **A8 — остатки LiveGrid** (частично). В `sitemap.xml` их уже нет, остальные места проверить.
