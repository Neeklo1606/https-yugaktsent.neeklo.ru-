# Исходники бренд-ассетов

Оригиналы логотипа и иконки в полном размере (1192×295). На сайт отдаются уменьшенные копии из `public/`:
высота 144 px — это 3× от максимальной высоты логотипа в шапке (48 px), чтобы знак оставался чётким на retina.
Пересобрать: уменьшить с сохранением пропорций и альфа-канала, без перекраски знака.
